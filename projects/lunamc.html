LunaMC

A Persian-language Minecraft server built around Bedwars, custom plugins, and a community that shows up every night.

What it is

LunaMC is my Minecraft server for the Persian community. The core is Bedwars, with custom plugins written for the server and a set of game modes that keep changing based on what players ask for.

How it runs

The server lives on a Linux VPS that I manage myself — Java, custom plugin builds, backups, and the network layer in front of it. ClutchPing actually started here, as the answer to players complaining about ping.
